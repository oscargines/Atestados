Atestados Project Documentation

This project provides a mobile application for generating and managing legal documents related to citations and alcohol-related incidents for judicial processes.

Overview

The application includes features for:





Managing citation data (CitacionDataProvider, CitacionViewModel).



Displaying a user interface for entering citation details (CitacionScreen).



Creating ViewModel instances (CitacionViewModelFactory).

Packages





com.oscar.atestados.data: Data providers and database access utilities.



com.oscar.atestados.screens: UI components built with Jetpack Compose.



com.oscar.atestados.utils: Utility classes for PDF generation and ViewModel factories.



com.oscar.atestados.viewModel: ViewModels for managing UI state and business logic.
